# Buscador de licitaciones de obra (Perú)

Revisa el SEACE dos veces al día, guarda obras, supervisiones y consultorías de obra en un buscador web y envía alertas por correo.

- Instalación: ver **GUIA.md**
- Filtros: `buscador/config.json`
- Buscador web: carpeta `docs/` (GitHub Pages)
- Prueba sin internet: `python pruebas/prueba_local.py`
